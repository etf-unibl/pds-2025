Detailed Description

Architecture arch for sequential multiplier.

FSM-based sequential multiplication architecture Contains control and data paths for iterative multiplication, including operand loading, accumulation, and result signaling.

Includes FSM control logic, datapath registers, routing multiplexer, functional units, and output logic
